Inbox GMAIL

Connect a Gmail account to JARVIS (5 minutes, once per account)
  1. Signed in as that account, open script.google.com → New project.
  2. Replace the code with gmail_bridge.gs from the jarvis-hub folder. Fill in HUB_KEY (from .hub-key), BUSINESS (atavia, es, lazo, roven, lr, brisk) and a long random SECRET.
  3. Run setup once (▶ in the toolbar) and approve the permissions.
  4. Deploy → New deployment → Web app → Execute as Me → Anyone → Deploy. Then run setup once more.
After that the inbox syncs every 5 minutes on Google's servers, and JARVIS can archive, mark read and send replies you confirm.
